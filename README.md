# RedColor

Редактор PDF для проверки работ. Интерфейс в духе Adobe Acrobat плюс инструменты, которые ускоряют проверку: бланки из папки, случайные цитаты, вставка формул с сайта как текста, подписи, настраиваемая панель инструментов и горячие клавиши на все команды.

**Автор:** Maksim Belonoskin, Zelenograd, Moscow, Russia.

## Возможности

- Просмотр и редактирование PDF во вкладках. Страницы рисуются в отдельном фоновом процессе, поэтому прокрутка не подвисает.
- Текст: по умолчанию красный, шрифт Minion Pro (если установлен Acrobat). Размер подстраивается под ширину страницы. Доступны все системные шрифты с кириллицей.
- Бланки подтягиваются из выбранной папки (с подпапками) и вставляются после текущей страницы. На бланк автоматически ставится случайная цитата под «Комментарий эксперта:».
- Красные «1» — остатки текстовых полей в комментариях бланков — убираются автоматически.
- Формулы: вставка с сайта (`Ctrl+V`) прямо в текст как векторные символы. Двойной щелчок открывает редактор LaTeX с автоматически восстановленным кодом формулы.
- Отметки: овал с номером, ✓ ✗ + – •, стрелки, фигуры, карандаш, маркер, ластик.
- Подписи: нарисовать, ввести красивым шрифтом или загрузить картинку с удалением фона.
- «Систематизация страниц»: перетаскивание, поворот, удаление, извлечение, вставка и замена.
- Плавающая панель инструментов: свой набор кнопок, порядок, поворот, закрепление, прикрепление к краю.
- Горячие клавиши на все команды, все переназначаются.
- Добавленные пометки остаются редактируемыми при повторном открытии файла в RedColor.

Подробная инструкция: [`assets/info.html`](assets/info.html), в программе — `F1`.

## Запуск из исходников

Нужен Python 3.14 (64-bit) для Windows.

```bash
py -3.14 -m pip install -r requirements.txt
py -3.14 RedColor.pyw
```

## Сборка установщика

Нужны PyInstaller и [Inno Setup 6](https://jrsoftware.org/isinfo.php).

```bash
py -3.14 -m pip install pyinstaller
py -3.14 installer\build.py
```

Результат: `installer\Output\RedColor_Setup_<версия>.exe`. Бланки и цитаты в установщик не входят — пользователь выбирает свою папку бланков и заполняет свои цитаты.

## Где хранятся данные пользователя

`%APPDATA%\RedColor`: настройки, `цитаты.txt`, подписи (`signatures`), свои шрифты (`fonts`), журнал ошибок (`log.txt`).

## Структура

| Путь | Назначение |
|---|---|
| `RedColor.pyw` | точка входа, один экземпляр программы |
| `rp/mainwindow.py` | главное окно, команды, бланки, цитаты, подписи |
| `rp/view.py`, `rp/items.py` | холст, инструменты, объекты на странице |
| `rp/document.py` | модель документа, отмена, сохранение, редактируемый слой |
| `rp/render.py`, `rp/render_proc.py` | фоновый рендер страниц |
| `rp/formula.py`, `rp/svg2tex.py`, `rp/clipboard.py` | формулы и вставка из буфера |
| `rp/blanks.py` | бланки, поле комментария, цитаты, удаление «1» |
| `rp/toolbar.py` | настраиваемая плавающая панель |
| `installer/` | сборка exe и установщика |
