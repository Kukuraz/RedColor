RedColor

Редактор PDF для проверки работ. Устроен как Adobe Acrobat, но с удобствами для проверки.
Автор: Maksim Belonoskin, Zelenograd, Moscow, Russia.

Быстрый старт

  • Откройте PDF: двойной щелчок по файлу (если RedColor выбран программой для PDF), перетаскивание в окно или Ctrl+O. Каждый файл — своя вкладка; повторное открытие файла попадает в уже запущенную программу.
  • Слева — панель «Редактировать», рядом — плавающая панель инструментов, справа — номер страницы и масштаб.
  • Любую команду можно найти в строке «Найти текст или инструмент» вверху справа.
  • Все действия отменяются Ctrl+Z и повторяются Ctrl+Y.

Бланки из папки

  • Укажите папку с бланками: левая панель → «Бланки» → «Выбрать папку…» (или Меню → «Выбрать папку бланков…»). Подойдёт любая папка с PDF; подпапки становятся подменю.
  • Список обновляется сам: положили новый PDF в папку — он сразу появляется в программе.
  • Вставка — после текущей страницы: щелчок по бланку в левой панели, клавиша B (меню бланков) или своя клавиша для конкретного бланка (назначается в «Горячих клавишах», раздел «Бланки»).
  • Папки, имя которых начинается с «_», не показываются (туда удобно складывать архив).

Случайные цитаты

  • При вставке бланка под надписью «Комментарий эксперта:» автоматически ставится случайная цитата. Цитаты не повторяются, пока не будет использован весь список.
  • Список цитат: Меню → «Цитаты…» (Ctrl+Alt+Q). Можно добавлять, править двойным щелчком, удалять, перетаскивать, искать, импортировать из .txt (одна цитата — одна строка) и экспортировать.
  • Изначально список пуст — заполните его сами.
  • Инструмент «Случайная цитата» (Q) — щелчок на странице; Shift+Q — цитата прямо под курсором.
  • Выделите свой текст на странице и выберите «Добавить выделенный текст в цитаты», чтобы пополнить список.
  • Автовставку цитаты можно выключить в меню бланков или в Настройках.

Красные «1» в комментариях

  • Остатки текстовых полей Акробата (красная «1» в поле «Комментарий эксперта») убираются автоматически при открытии документа. Вернуть — Ctrl+Z.
  • Вручную: «Убрать «1» в комментариях бланков» (Ctrl+Alt+1).
  • Очистить сами файлы бланков: меню бланков → «Убрать «1» во всех бланках папки…». Оригиналы сохраняются в подпапку «_оригиналы с единицами».

Текст

  • Инструмент «Добавить текст» — T, щелчок на странице и печать. Двойной щелчок по тексту — правка.
  • По умолчанию текст красный, шрифт Minion Pro (как в Акробате; если Акробата нет — Times New Roman). Шрифт, размер, цвет, выравнивание, полужирный и курсив — в разделе «Форматировать текст».
  • Авторазмер: размер текста подстраивается под ширину страницы, поэтому на больших сканах он остаётся читаемым. Кнопка «Подогнать» (Ctrl+Shift+F) делает это для выделенного текста.
  • Цвета: Alt+1 красный, Alt+2 чёрный, Alt+3 синий, Alt+4 зелёный. Размер: Ctrl+] / Ctrl+[.
  • Свои шрифты (.ttf/.otf) кладите в папку fonts в данных программы (см. ниже) и перезапустите RedColor.

Формулы с сайта (копировать → вставить)

  • Выделите на сайте текст вместе с формулами, Ctrl+C, затем в RedColor Ctrl+V. Текст станет обычным редактируемым текстом, а формулы встанут внутрь него как символы — векторные (чёткие при любом масштабе) и в цвет текста.
  • Если вставка не помещается, она сама сдвигается и уменьшается, чтобы влезть на страницу.
  • Исправить формулу: двойной щелчок по тексту (режим правки), затем двойной щелчок по формуле — откроется редактор LaTeX. LaTeX формулы с сайта восстанавливается автоматически; проверьте и поправьте, справа сразу виден результат.
  • Новая формула — инструмент «Формула» (F). Поддерживаются дроби, корни, векторы, индексы и степени, греческие буквы, системы \begin{cases} … \\ … \end{cases}, кириллица через \text{кг}.

Другие вставки из буфера

  • Скопированная картинка вставляется изображением, обычный текст — текстом.
  • Объекты RedColor (текст, фигуры, подписи) копируются и между документами: Ctrl+C / Ctrl+V, Ctrl+D — дублировать.

Отметки и рисование

  • Овал (O), овал с номером (N — номера идут по порядку на каждой странице), прямоугольник (R), линия (L), стрелка (A), галочка (K), крестик (X), плюс (=), минус (-), точка (.).
  • Щелчок ставит отметку стандартного размера, протягивание задаёт размер. С Shift — сохранение пропорций.
  • Карандаш (P), маркер (U), ластик (E, стирает линии карандаша целиком). Цвет и толщина — «Линии» в левой панели.

Подписи

  • Вкладка «Электронное подписание» или кнопка подписи на панели: «Добавить подпись…» — нарисовать мышью, ввести текстом красивым шрифтом или загрузить картинку (белый фон удаляется).
  • Щелчок по подписи в списке, затем щелчок на странице. Цвет подписи меняется в той же вкладке. Каждой подписи можно назначить клавишу.

Плавающая панель инструментов

  • Перетаскивайте её за полоску сверху. Двойной щелчок по панели — повернуть (вертикально/горизонтально).
  • Правый щелчок по панели — меню: закрепить, прикрепить к краю (слева/справа/сверху/снизу), размер значков, скрыть, сбросить.
  • «Настроить панель…» (Ctrl+Alt+T): добавляйте любые команды (в том числе отдельные бланки и подписи), убирайте, меняйте порядок перетаскиванием, вставляйте разделители.
  • F8 — показать/скрыть панель, Ctrl+Alt+R — повернуть.
  • Кнопки с маленьким треугольником — группы: щелчок выбирает последний инструмент группы, щелчок по треугольнику или правой кнопкой — весь список.

Страницы

  • «Систематизация страниц» (Ctrl+Shift+O): перетаскивайте миниатюры, выделяйте чётные/нечётные/все, поворачивайте, удаляйте, извлекайте, вставляйте и заменяйте. Ctrl+колесо — размер миниатюр.
  • Пустая страница после текущей — Ctrl+Shift+T; поворот — Ctrl+Shift+= / Ctrl+Shift+-; удалить страницу — Ctrl+Shift+D.

Сохранение

  • Ctrl+S — сохранить, Ctrl+Shift+S — сохранить как.
  • Всё добавленное остаётся редактируемым, если снова открыть файл в RedColor. В других программах файл выглядит как обычный PDF.
  • Если файл открыт в другой программе (например, в Adobe Acrobat), Windows не даёт его перезаписать — появится окно «Повторить / Сохранить как…». Закройте файл там и нажмите «Повторить»; изменения не теряются.

Горячие клавиши

  • У каждой команды есть сочетание, все переназначаются: Меню → «Горячие клавиши…» (Ctrl+Alt+K). Поиск, два сочетания на команду, предупреждение о совпадениях, сброс.
  • Основные: V выделение, H рука, Пробел+мышь — прокрутка рукой, Ctrl+колесо — масштаб, Ctrl+0 страница целиком, Ctrl+2 по ширине, стрелки — сдвиг объекта (с Shift — на 10 pt), Del — удалить, Esc — снять выделение.

Где хранятся ваши данные

Папка данных%APPDATA%\RedColor
Цитаты%APPDATA%\RedColor\цитаты.txt
Подписи%APPDATA%\RedColor\signatures
Свои шрифты%APPDATA%\RedColor\fonts
Журнал ошибок%APPDATA%\RedColor\log.txt

Удаление программы эти данные не трогает.
